# 🗄️ Curso Completo de SQL y Bases de Datos (MySQL)

Repositorio de apuntes, scripts y ejercicios prácticos desarrollados a lo largo del **[Curso de SQL y Bases de Datos de MoureDev](https://www.youtube.com/watch?v=OuJerKzV5T0)**.

El objetivo de este repositorio es documentar el aprendizaje progresivo de sentencias SQL, modelado relacional y conceptos avanzados de administración de bases de datos.

---

## 📂 Estructura del Repositorio

La carpeta del proyecto está organizada por módulos temáticos siguiendo el avance práctico del curso:

```text
MySQL_course/
├── Statements/          # Consultas de lectura, filtrado, ordenación y agrupaciones
│   ├── 01_select.sql
│   ├── 02_distinct.sql
│   ├── 03_where.sql
│   ├── 04_order_by.sql
│   ├── 05_like.sql
│   └── ...
├── Writing/             # Manipulación y escritura de datos (CRUD)
│   ├── 01_insert.sql
│   ├── 02_update.sql
│   └── 03_delete.sql
├── Tables/              # Definición de esquemas, tipos de datos y constraints
│   ├── 01_create_table.sql
│   ├── 02_drop_table.sql
│   └── 03_alter_table.sql
├── Relations/           # Creación y gestión de claves foráneas (1:1, 1:N, N:M)
├── Joins/               # Consultas multitabla (INNER, LEFT, RIGHT, UNION)
└── Advanced/            # Índices, Triggers, Views, Procedimientos y Conectores
