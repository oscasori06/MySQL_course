# 🗄️ Curso Completo de SQL y Bases de Datos (MySQL)

Repositorio de apuntes, scripts y ejercicios prácticos desarrollados a lo largo del **[Curso de SQL y Bases de Datos de MoureDev](https://www.youtube.com/watch?v=OuJerKzV5T0)**.

El objetivo de este repositorio es documentar el aprendizaje progresivo de sentencias SQL, modelado relacional y conceptos avanzados de administración de bases de datos.
